# Coworker demo updates

This repository distributes compiled Windows demo updates. Development source and CI stay in a separate private repository.

Download the program ZIP and `SHA256SUMS` from the [latest release](https://github.com/Mag357num/coworker-demo-updates-20261110/releases/latest). The ZIP contains only the program and version metadata. No GitHub account is required to download a published release.

Update clients read `https://api.github.com/repos/Mag357num/coworker-demo-updates-20261110/releases/latest`, download the matching Windows asset, and verify its SHA-256 before use.

These files are a pipeline demonstration, not a production application.
